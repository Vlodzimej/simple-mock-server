# Проверка расширенного журнала, 25 ноября 2026

## Проверки реализации

- `dotnet test`: 39/39 PASS. Захват обеих сторон, заголовки/query/тела,
  вложенное маскирование, JSON/XML/multipart, бинарный ответ, gzip,
  усечение, необычные форматы и потоковая отправка через реальный Kestrel.
- Проверка миграции: сохранение старой сессии, её состояния и записи без details.
- Сохранение 5002 записей без автоматической очистки; API-фильтры до пагинации,
  курсор, изоляция подробностей и удаления по сессии, сохранение состояния checked
  после очистки журнала. Новые MCP-инструменты вызваны настоящим MCP-клиентом.
- Поиск кириллицы в теле ответа без учёта регистра. JSON подробностей сохраняет
  Unicode, SQLite lower использует ToLowerInvariant.
- Production-сборка Angular: Node 24, exit 0, без ошибок компиляции и budget warnings.
- Playwright: 5/5 PASS. Вкладки, сохранение несохранённого JSON при переключении,
  105 запросов через три страницы, все поля фильтров, подробности,
  ошибка подробностей 503 и повтор, выбор, отмена удаления, удаление одной записи,
  очистка оставшихся 104 при активном фильтре без совпадений.
- Светлая и тёмная темы, ширины 320/820/1440 px, текст 200%, клавиатура и
  отсутствие pageerror. Скриншот: `work/journal-desktop.png`.
- Независимый обзор: исправлены исключения на повторных ключах JSON,
  multipart/mixed и неподдерживаемой кодировке; предварительное чтение запроса
  заменено перехватом чтения; сжатые тела распаковываются с пределом перед
  маскированием. Найденные случаи закреплены тестами.

## Практические границы

Максимум 256 KiB на каждую сторону. Некорректные или усечённые структурированные
тела могут быть пропущены с note, содержимое файлов multipart не сохраняется.
Невозможно автоматически распознать все секреты в произвольном тексте, пути или
бинарном содержимом. Старые записи остаются без details. Для бесконечного или
рано завершённого потока сохраняется прочитанная часть запроса.

Пользовательская база cabinet-staging не изменялась. Добавочная миграция
применяется при запуске нового backend с выбранной DatabasePath. Физическое
устройство и внешний backend в этой работе не проверялись.
