# Архитектура Simple Mock Server

Сервис обслуживает произвольные HTTP API через изолированные тестовые сессии. Фиксированных прикладных endpoint и демонстрационных данных при запуске нет.

## Состав

- `MockServer.Core`: конфигурация сессии/правила, валидация и сопоставление пути/JSON.
- `MockServer.Infrastructure`: SQLite-хранилище сессий/журнала, блокировки, проверка upstream и HTTP forwarding на YARP.
- `MockServer.Api`: HTTP administration, диспетчер запросов `/s/{id}/…` и MCP tools.
- `web`: Angular-панель HTTP-сессий.
- `MockServer.Tests`: HTTP, SQLite и MCP интеграционные тесты.

## Обработка запроса

Сервер определяет сессию из URL, удаляет служебный префикс и сопоставляет оставшийся путь с правилами. Условия метода, query, заголовков, form, JSON и состояния объединяются через AND. Приоритет выбирает правило; неоднозначность не допускает вызов upstream.

Совпавшее правило возвращает мок. Без совпадения запрос передаётся на upstreamBaseUrl, кроме защищённых путей. Ошибка мока не включает fallback.

Исходный escaping пути, query, HTTP-метод и тело сохраняются. Hop-by-hop заголовки исключаются; redirect и cookies не переписываются. Маркер экземпляра предотвращает петлю до ожидания блокировки сессии.

## Состояния и данные

Запросы и изменения в пределах сессии выполняются последовательно. nextState резервируется при выборе правила, до задержки/отправки ответа. Reset возвращает initialState и очищает журнал; правила остаются. Экспорт исключает id/историю/текущее состояние, импорт создаёт новый id.

Активная модель SQLite содержит Sessions и SessionRequests. Цепочка миграций обеспечивает переход существующей БД; неиспользуемые таблицы удаляются миграцией SessionOnlyStorage. Перед обновлением существующей БД рекомендуется резервная копия.

История ограничена 5000 запросами на сессию. В ней сохраняются метод, путь, выбранное правило, источник, статус, длительность и причина. Тела, query и заголовки не записываются.

## Интерфейсы

HTTP administration: `/admin/api/sessions`. MCP: `/mcp` с официальным C# SDK. Оба интерфейса используют SessionStore, поэтому правила валидации и изменения состояния общие. MCP transport state не является тестовой сессией.

Основной UI: `/sessions`; корень приложения открывает эту страницу. Панель редактирует переносимый JSON, показывает адрес подключения и журнал, поддерживает импорт/экспорт, reset, защиту правок и обе темы.

Формат, лимиты и примеры: [HTTP-сессии](http-sessions.md).
