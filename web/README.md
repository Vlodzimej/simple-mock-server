# Панель Simple Mock Server

Установка: Node.js 24, затем npm ci. Запуск: npm start (dev proxy на backend localhost:5080).
Сборка: npm run build. Браузерные проверки: npx playwright install chromium, затем npm test.

Панель открывает HTTP-сессии: конфигурация произвольных правил, адрес подключения, состояния, журнал и импорт/экспорт.
